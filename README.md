# DEZECE

Presentation website for a company selling pergolas and glass enclosures.

## Overview
A marketing site built to present the company's services and showcase 
completed installations. The portfolio section is the centrepiece — visitors 
are choosing based on how previous work looks, so the layout is built around 
a project gallery rather than text.

## Features
- Services overview
- Portfolio gallery of completed installations
- Responsive layout across desktop, tablet and mobile
- Contact section

## Tech stack
- React
- Tailwind CSS

## Notes
Built for a client. Designed and implemented end to end
